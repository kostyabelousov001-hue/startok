# 🌐 StarTok Backend Server

Легковесный бэкенд для экосистемы **StarTok**:
- **Раздача бейджей и ролей**: Создатель (Creator), Тестер (Tester), Юзер (User).
- **StarBump Matching**: Алгоритм сопоставления одновременной тряски телефонов рядом.
- **Cloud Sync**: Резервное копирование и экспорт настроек мода.

---

## 🚀 Быстрый запуск локально:

```bash
cd backend
npm install
npm start
```
Сервер запустится на `http://localhost:3000`.

---

## ☁️ Бесплатный деплой в облако (1 клик):
1. **Render.com / Railway.app / Vercel**:
   - Подключи свой GitHub репозиторий.
   - Укажи root directory: `backend`.
   - Build Command: `npm install`.
   - Start Command: `npm start`.
2. Полученный URL (например `https://your-startok-api.onrender.com`) вставь в настройки мода в приложении или в `StarTok.h`!
