# 🌟 StarTok Ultimate — Полная документация проекта

**StarTok** — это кастомная модификация и экосистема для TikTok на iOS с полной поддержкой всех нативных функций, уникальными серверными SVG-бейджами, социальным бампом при тряске телефонов, чат-движком и мощным комплексом улучшений интерфейса.

---

## 📂 Структура проекта

```
ttmod/
├── .github/workflows/
│   └── build.yml               # Авто-сборка Theos dylib + инъекция в IPA через Pyzule
├── backend/                    # Серверная часть (Node.js / Express)
│   ├── server.js               # API бейджей, ролей, StarBump и синхронизации настроек
│   ├── package.json            # Зависимости бэкенда
│   └── README.md               # Инструкция по деплою на Render/Railway/VPS
├── control                     # Идентификатор пакета для Theos
├── Makefile                    # Сценарий сборки Theos для компиляции всех модулей
├── StarTok.h                   # Глобальные константы, модели, ключи настроек и менеджер
├── StarTok.plist               # Фильтр Bundle ID (com.zhiliaoapp.musically, etc.)
├── StarTokManager.m            # Синглтон: работа с бэкендом, кэш ролей, датчик тряски, Taptic Engine
├── StarBadges.xm               # Серверные SVG-бейджи (Создатель 👑, Тестер 🧪, Юзер ⭐, Молния ⚡)
├── StarChat.xm                 # Чат-движок (!spam, !spoof seen/typing/online, !mute, !help, Streak Saver)
├── StarGuard.xm                # Анти-спам стоп-лист: моментальный краш (exit 0) при запрещенке
├── NomadMode.xm                # Режим загадочного иностранца (гостевой прыжок в JP/US/FR/BR/BY/KZ)
├── MediaDownloader.xm          # Скачивание без водяных знаков + Avatar HD Zoom по долгому тапу
├── UIEnhancements.xm           # OLED 100% черный, StarSpeed перемотка удержанием, Anti-Ads, Ghost View
├── StarSettings.xm             # Нативное Inset Grouped меню настроек прямо в профиле TikTok
└── TTRoot.xm                   # Точка входа и инициализация твика
```

## 🔥 Полный список реализованных фичей

### 👑 1. Серверные SVG-бейджи & StarBump
- **Роли пользователей:**
  - `Создатель` — Золотая корона/звезда с тапом по бейджу и инфой о создателе.
  - `Тестер` — Фиолетовая неоновая колба/звезда.
  - `Юзер` — Фирменная векторная звезда StarTok.
- **StarBump (Shake to Bump):**
  - При одновременной тряске двух айфонов рядом акселерометр (`CMMotionManager`) отправляет сигнал на бэкенд.
  - При совпадении таймстемпов срабатывает вибрация `Taptic Engine`, вылезает алерт *«Вы забампились!»*, а рядом с ником друга появляется значок молнии `⚡` («Забампились в реале»).

### 💬 2. Чат-движок (In-Chat CLI & Streaks)
- **Команды в сообщениях:**
  - `!spam <текст> <кол-во>` — отправка серии сообщений с безопасной микрозадержкой.
  - `!spoof seen <время>` — отложенный статус «Прочитано».
  - `!spoof typing <время>` — бесконечный статус «Печатает...».
  - `!spoof online <время>` — спуфинг статуса «В сети».
  - `!mute <время>` — локальное глушение чата.
  - `!help` — всплывающая справка по всем командам.
- **Streak Saver:** Автопроверка и фоновый пинг перед сгоранием 24-часовых огоньков.
- **Ghost Typing:** Отключение индикатора набора текста в ЛС.

### 🛡️ 3. StarGuard (Instant Crash Anti-Spam)
- Перехватывает отправку комментариев и сообщений.
- При обнаружении запрещенных спам-фраз моментально блокирует отправку и выполняет мгновенное завершение приложения (`exit(0)`).

### 🌍 4. Nomad Mode & Нативный TikTok
- **Режим загадочного иностранца:** Временный переход в ленту Японии, США, Франции, Бразилии или Беларуси без загрязнения алгоритмов основного аккаунта.
- **100% Native Unlocked:** Полная работоспособность официальных аудио/видео звонков, войсов, стикеров, фото в комментариях и HD-медиа в ЛС.

### 🎬 5. Медиа, UI & Скорость
- **No Watermark:** Чистые видео без вотермарок и плашек автора.
- **Avatar HD Zoom:** Долгий тап по любой аватарке открывает её в полном качестве с кнопкой сохранения в Фото.
- **StarSpeed Hold:** Удержание пальца на видео плавно ускоряет его до **2.5x**.
- **Ghost View:** Скрытый просмотр историй и профилей без отображения в списках гостей.
- **OLED Pure Black:** Истинный 100% глубокий черный цвет для экономии батареи и эстетики.
- **Sponsored Ads & TikTok Shop Nuker:** Полное вырезание рекламных видео и баннеров покупок.
- **Taptic Feedback Everywhere:** Приятные тактильные виброотклики на лайки, бампы, скачивание и команды.

## 🚀 Как собрать готовый IPA через GitHub Actions

1. Создай репозиторий на GitHub и запушь все файлы:
   ```bash
   git init
   git add .
   git commit -m "feat: complete StarTok Ultimate mod and backend"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_АККАУНТ/startok.git
   git push -u origin main
   ```
2. Открой вкладку **Actions** в репозитории.
3. Выбери воркфлоу **"Build StarTok Ultimate IPA"** -> нажми **"Run workflow"**.
4. В поле `ipa_url` укажи прямую ссылку на расшифрованный `.ipa` TikTok (decrypted).
5. В поле `target_region` укажи желаемый регион (по умолчанию `US`).
6. После завершения скачай готовый файл из **Artifacts** (`StarTok_Ultimate_US.zip`) и подпиши через Scarlet, TrollStore, AltStore или GBox!
